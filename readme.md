# Плейлист

Страница с плейлистами, с возможностью фильтрации по названию и жанру. При клике на плейлист открывается страница с его треками, где отображаются название и кликабельный жанр — при нажатии на жанр происходит возврат к отфильтрованному списку плейлистов. Название плейлиста также отображается и активно на странице пользователя, ведя к списку треков.
